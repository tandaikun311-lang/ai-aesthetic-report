# 下载、安装并直接使用说明

目标：让另一台 Mac 下载仓库后，可以直接安装 Codex 技能，并使用命令行渲染报告。

## 一、前提条件

目标电脑需要：

- macOS
- Python 3.10 或以上
- Git
- Codex 本地环境
- 可以访问这个 GitHub 仓库

当前仓库是私有仓库。别人要下载，必须满足以下任一条件：

1. 被添加为 GitHub collaborator。
2. 使用有权限的 GitHub 账号登录。
3. 你把仓库改成 Public。

如果要保持项目资料安全，建议先用 collaborator 权限，不建议直接公开。

## 二、下载仓库

```bash
cd ~/Downloads
git clone https://github.com/tandaikun311-lang/ai-aesthetic-report.git
cd ai-aesthetic-report
```

如果没有 GitHub 权限，会提示无权访问。需要先让仓库所有者添加权限。

## 三、一键安装

```bash
bash install.sh
```

安装脚本会自动完成：

- 复制技能到 `~/.codex/skills/face-consultation-report`
- 复制智能体分工、报告规范、渲染脚本、网资模板
- 创建 Python 虚拟环境
- 安装 `Pillow`
- 创建命令行入口：
  - `~/.local/bin/face-report-v2`
  - `~/.local/bin/face-report-basic`
- 运行安装自检

如果终端找不到 `face-report-v2`，执行：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

想永久生效，可以加到 `~/.zprofile`：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zprofile
```

## 四、验证安装

```bash
python3 scripts/validate_install.py --target ~/.codex/skills/face-consultation-report
```

看到 `[OK] validation complete` 就说明安装正常。

## 五、使用方式一：在 Codex 里直接调用技能

安装完成后，在 Codex 里可以这样说：

```text
使用 face-consultation-report 技能，把这张客户正脸照片生成 AI 美学升级报告。
交付顺序要包含：原图、客户 AI 效果图、效果标记图、报告图、网资沟通细节。
```

注意：AI 效果图仍需要图像生成能力支持。这个仓库提供的是报告工作流、文案规则、渲染脚本和模板，不内置第三方图片生成账号。

## 六、使用方式二：命令行渲染报告图

复制示例配置：

```bash
cp sample/manifest.example.json /tmp/face-report-manifest.json
```

编辑 `/tmp/face-report-manifest.json`，把这三个字段改成真实本机路径：

```json
{
  "before_image": "/absolute/path/to/client-before.jpg",
  "effect_image": "/absolute/path/to/client-ai-effect-clean.png",
  "after_image": "/absolute/path/to/client-ai-effect-annotated.png"
}
```

运行：

```bash
face-report-v2 \
  --manifest /tmp/face-report-manifest.json \
  --out "$HOME/Downloads/面诊报告_测试"
```

输出目录会包含：

- `report-v2.html`
- `report-v2.png`
- `assets/`

## 七、卸载

```bash
bash uninstall.sh
```

会删除：

- `~/.codex/skills/face-consultation-report`
- `~/.local/bin/face-report-v2`
- `~/.local/bin/face-report-basic`

## 八、隐私规则

不要把以下内容提交到 GitHub：

- 客户原图
- AI 效果图
- 标记图
- 报告截图
- 含客户人脸的 Word、Excel、PDF
- 客户姓名、电话、微信、门店隐私信息

仓库 `.gitignore` 已默认忽略常见图片格式，但使用前仍要检查：

```bash
git status --ignored -sb
git ls-files | grep -Ei '\\.(jpg|jpeg|png|webp|heic)$' || true
```
