# 标准模板：2026-05-27 原版 V2 美学升级报告

本仓库以用户选定的 2026-05-27 原版报告为版式标准。公开仓库仅保存模板规则、渲染代码和合成示例，不包含原报告中的真人照片、标记图或报告截图。`scripts/render_sales_v2.py` 的页面 CSS 与原版报告一致；不要通过重画页面来替代此渲染器。

## 固定画面

- 页面内容宽度 1600 CSS 像素；在 2 倍截图倍率下，标准 PNG 宽度为 3200 像素。高度随文本内容变化，不强制裁成 16:9。
- 浅蓝白底、深蓝主字、细边框、克制的蓝色编号与标签。页头是编号、居中主标题和副标题、右侧定性视觉观感卡。
- 主区四列：左侧原图观察 210px；原图 445px；带编号标记的 AI 效果图 445px；右侧项目映射 400px。列间距 14px。两张人像始终是视觉中心。
- 左侧最多四条本案可见观察。右侧最多五条映射，每条包含局部裁切图、变化名称、项目方向、两条视觉细节和沟通问题。没有证据支持的项目不得为了填满五条而添加。
- 底区四列：`美学设计思路` 一列，加三张按优先级排序的建议卡。页脚标注 AI 视觉模拟和非医疗诊断边界。
- 报告内的 After 使用从干净 AI 效果图制作的编号标记图；干净效果图另作为独立交付物。原图、干净效果图、标记图不得互相冒充。

## 每案替换内容

将 `sample/manifest.example.json` 复制到仓库外或 Git 忽略的本机目录，填写该客户的原图、干净 AI 效果图、标记图、标题、副标题、定性视觉观感、四项观察、可验证的项目映射、设计思路、三条建议。不要把示例文案当作真人诊断。

观察和项目方向必须对应照片中可见的变化。只描述视觉观感，具体项目、适应证、材料和治疗方案由有资质的专业人员面诊决定。不得写具体减龄岁数、必然效果、报价或未经确认的医疗结论。

## 验收

1. 用合成示例先运行 `python3 scripts/self_check.py --with-screenshot`；检查 `outputs/self-check-demo/report-v2.png` 能完整打开，宽度为 3200 像素，页头、四列主区和四列底区均未被裁切。
2. 用本案 manifest 渲染后，逐一检查原图、干净效果图、标记图是三个不同文件；After 身份与姿态可对照，脸部和编号没有被裁掉。
3. 检查每条观察、映射与建议均属于本案；文字不溢出卡片；右侧项目与标记点一致；免责声明可读。
4. 核对 `00_交付入口.html` 的四张图链接和咨询资料，再交付。客户素材只保存在私有项目目录，不提交 GitHub。

如果需要展示标准效果，请在本机运行合成 demo。公开仓库没有真人版标准截图。
